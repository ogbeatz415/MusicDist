Organize your music, check the essentials, and prepare a release for delivery onboarding.

1. Connect your admin session

Held only in this page’s memory. This is an owner workspace; artist accounts are not enabled.

2. Create a release draft

Import a release JSON or edit the template below. Use your assigned UPC and ISRC codes, actual credits, and selected territories. Set rights_confirmed to true only after checking your rights.

3. Upload original assets

Lossless stereo WAV, FLAC, or ALAC masters and square RGB artwork. Uploads remain private. Files up to 1 GiB use a single PUT; keep this tab open.

Create a draft to attach its files.



4. Prepare your package
Download unchanged masters, artwork, metadata, and checksums in one ZIP. Each DSP stays marked “not connected” until an approved delivery integration is added.


No DSP submission is enabled. Preparing a package does not publish a release.
